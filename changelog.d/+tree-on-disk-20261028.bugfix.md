A python or shell write to a state file in the tree was refused when the line spelled the tree through a symlink. An example is `/workspace/state/seen.json` with `/workspace` a link. The tree is the directory the line runs in, which the system names by its real path. The written path was only folded as text, so it did not start with that real path. A link in the tree that points out of it was let through the same way. The written path and the tree are now both read from the disk before they are compared, with each link followed. A link with no target yet is followed too. Temp and device paths are judged as spelled, as before.
