A write out of the tree through `curl -o`/`--output`, `wget -O`, `ln`, `rsync`, `truncate` or `tar` was not placed, so only a redirect, `cp`, `mv`, `install`, `dd`, `sed -i`, `perl -i` or `awk` to the same path was refused. Each now lands where its target says and is refused as `writes-outside` when that is out of the tree: what `curl` and `wget` save, the link `ln` makes, the destination of `rsync`, a file `truncate` sizes, the `-C` directory a `tar` extract writes into, and the archive a `tar -c` creates. A remote `rsync` destination, a download to stdout and the same writes inside the tree or under `/tmp` are allowed.
